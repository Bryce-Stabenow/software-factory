# Kulumin identity

The approved mark is a compact ship with three swept sails and a low hull. Use three solid amber shades, with no letter, outline, or decorative line details.

- Deep amber: `#f59e0b`
- Amber: `#fbbf24`
- Light amber: `#fcd34d`
- App-icon background: neutral `#171717`

The canonical artwork is `apps/desktop/public/kulumin-mark.svg`. The sidebar uses it directly. Run `npm run icons` to generate the browser app SVG, native app SVG, PNG sizes, and macOS ICNS. `npm run package:desktop` runs this generation automatically before building and signing the app.

Generated artwork belongs in source control. Edit the canonical mark rather than individual generated files. Keep its aspect ratio, tight spacing, and amber colors in both interface themes. Earlier screenshots in the verification history show superseded designs; the README uses the current branding.
